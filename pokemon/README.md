# ポケットモンスター版 図鑑協力調査

ブルーアーカイブ版と同じ2人協力型カードゲームを、独立したフォルダに複製した版です。元版の `index.html`、`content.json`、`ContentEditor.html` は変更していません。

同じ実行ファイルを `publish/pokemon/` にも配置しています。元版の `publish/index.html` は変更していません。

## 起動

`pokemon` フォルダを静的サイトとして公開するか、ローカルサーバーで開きます。

```powershell
python -m http.server 8765 --directory pokemon
```

ゲームは `http://localhost:8765/`、カード編集画面は `http://localhost:8765/ContentEditor.html` です。2人対戦の接続には元版と同じPeerJSの外部サービスを使います。

## カードと設定

- 全国図鑑No.1～1025の全1025種と、条件に合う姿違い244件の計1269枚を収録しています。PokéAPIに姿違いが3種類以上登録されている種族は、元の姿とメガシンカの姿だけを残します。姿違いが1～2種類の種族は、その姿も別カードです。
- メガシンカのカード名は「メガクチート」のように単独で表示します。
- 世代は種族が初登場した世代（第1～第9世代）で分類し、姿違いも同じ世代に所属します。
- ホストが世代ごとにON/OFFを設定できます。「最終進化のみ」は、その種族から進化する別種がないカードだけを候補にします。進化しない単独種やその姿違いも含みます。
- カードに約0.5秒マウスを乗せると、全国図鑑No.、世代、姿ごとのタイプを表示します。編集画面でメモを追加してもタイプ表示は残ります。
- 25枚未満の設定ではルーム作成を止めます。選択した世代と最終進化設定はホスト側で盤面生成に使い、盤面とタイプ情報は参加者に同期されます。

`ContentEditor.html` ではカード名、全国図鑑No.、タイプ、最終進化判定、メモを編集できます。編集内容はブラウザ内に自動保存されます。ゲームに反映するには `content.json` を書き出し、このフォルダの同名ファイルと置き換えてください。

## データ出典と更新

種族、姿、タイプ、進化関係、日本語名は [PokéAPIの公開データ](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv) から2026年9月16日に生成しました。全国図鑑の1025種という範囲は[ポケットモンスター公式サイト](https://www.pokemon.co.jp/goods/2026/260515_da01.html)でも確認できます。PokéAPIで日本語名が欠けている姿は生成スクリプトで補っています。将来データが増えた場合は `tools/build_data.py` を再実行し、その後 `tools/build_variant.py` を再実行します。データ再生成は手動編集した `content.json` を上書きします。

## 確認

```powershell
node pokemon/tools/check-hover.js
```

`tools/smoke.html` はブラウザで世代切替、最終進化フィルター、編集画面の初期表示を確認するためのページです。
